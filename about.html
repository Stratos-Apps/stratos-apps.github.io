About Stratos Apps

Based in Canada, Stratos Apps was founded by Developer Dude in 2026. He decided that the community needs more open source tools to improve their computing. Stratos Apps is just that, providing security tools such as a password generator and a checksum file verifier, along with other projects that can be found on GitHub. If you enjoy the apps, please leave a star on Github and follow the project so you don't miss anything.
